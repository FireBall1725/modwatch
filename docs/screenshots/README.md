# Screenshots

Every screen of the dashboard, taken against a database filled with made-up data. The author, the nine mods (Sample Mod 1 to Sample Mod 9), the issues repository and every download count are invented. Nothing here comes from a real CurseForge, Modrinth or GitHub account.

The data covers 90 days of snapshots (hourly for the last 48 hours, every six hours before that): 15 platform projects, 148 files, 11 issues and a Modrinth revenue history. The nine mods are there to show the states the UI has to handle:

- Sample Mod 1: on both platforms, with an open crash and an open bug.
- Sample Mod 2: Modrinth listing in review, no file for Minecraft 26.3.
- Sample Mod 3: a legacy mod that stays on Minecraft 1.12.2 and 1.7.10.
- Sample Mod 4: only on CurseForge.
- Sample Mod 5: Modrinth listing is a draft.
- Sample Mod 6: up to date on every version it supports.
- Sample Mod 7: no file for Minecraft 26.3.
- Sample Mod 8: published about six weeks ago.
- Sample Mod 9: a mod the author is a member of but doesn't own.

Sample Mod 3 only shows with "Show legacy mods" on, and Sample Mod 9 only with "Show member mods" on. Minecraft 1.7.10 is switched off in Settings.

Desktop shots are 1600 px wide. Phone shots are 390 px wide at 2x, cropped to the first screens.
